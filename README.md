# 🗡️ Zelda PC Port Desktop Icons

**Give your desktop a little Hyrule.**

A collection of custom-designed Windows desktop icons for the Zelda PC port community.

This project features six unique, Zelda-inspired icon designs created to give your favorite PC ports their own desktop identity.

## ✨ Features

- Custom game-inspired artwork
- Windows `.ico` format
- Multiple icon resolutions (16px–256px)
- 512 × 512 PNG previews
- Compatible with Windows 10 and Windows 11

## 🖥️ Installation

1. Download and extract the ZIP archive.
2. Locate the `.ico` file for your game.
3. Right-click your game's desktop shortcut.
4. Select **Properties**.
5. Under the Shortcut tab, select **Change Icon**.
6. Browse to your extracted `.ico` file.
7. Select Apply, then OK.

Enjoy your upgraded desktop!
